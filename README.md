# Avañe'ẽ — Aprendiendo guaraní

Sitio web del Módulo 1 de idioma guaraní (Unión de Pueblos Originarios · Municipio de Tigre).

Incluye las 4 clases en formato escrito, con audios de pronunciación y ejercicios interactivos.

## Desarrollo

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Contenido

El material original está en `contenido_clases/` (PDFs y audios). El contenido publicado en el sitio vive en `src/data/classes.ts` y los audios en `public/audio/`.
